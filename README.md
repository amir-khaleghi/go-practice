# Go Practice

## Introduction

This repository contains various projects and exercises aimed at improving proficiency in the Go programming language. It covers fundamental concepts, practical exercises, and real-world applications, including CLI development.

## 0 - Introduction to Go

This section includes solutions to various problems from platforms like Exercism and other coding challenge websites. The focus is on learning and implementing the basic features of Go, such as:

- Go syntax and semantics
- Control structures
- Functions and methods
- Error handling
- Data structures (slices, maps, structs, etc.)

## 1 - Command Line Interfaces (CLI)

In this section, I've built several command-line tools to explore best practices in CLI development. These projects demonstrate how to:

- Create interactive command-line applications
- Parse command-line arguments and flags
- Implement CLI commands and subcommands
- Handle user input and error cases effectively

Each CLI project showcases practical use cases, offering insights into structuring Go applications for various utilities.
